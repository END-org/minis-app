# MINIS R&D Research Repository Seed

## Purpose

This repository is intended for a focused R&D investigation into production deployment and release-readiness options for MINIS. It should contain research notes, official-source evidence, reproducible experiments, comparison matrices, and final recommendations.

The expected research window is seven working days. The release context is approximately two months from the assignment start.

## Required Workstreams

1. Firebase versus Supabase Authentication
2. Deployment, PostgreSQL, and Object Storage
3. Upload and MVP Video Delivery
4. Android and iOS Release Readiness

## Required Outputs

- Completed stakeholder-input notes.
- Provider and option comparisons using official sources.
- Decision matrix and cost model.
- Research log.
- At least the required deployment and object-storage experiments.
- Final report with one primary recommendation and one fallback.

## GitHub Workflow

- Open one issue per workstream or decision group.
- Use pull requests for research updates.
- Link evidence and official sources in every PR.
- Keep assumptions visible and dated.
- Use reproducible experiment notes instead of private screenshots when possible.

## Rules

- Do not store secrets, credentials, private keys, local `.env` files, service-account JSON, prepared-account passwords, or private media in this repository.
- Use official provider documentation, console-exported facts, and reproducible experiments.
- Do not implement production infrastructure.
- Do not publish final mobile apps.
